# Blog 폴더 안내

이 폴더가 https://saimino.github.io 의 원본입니다.

- 새 글은 AI, Math, Paper, Others 중 맞는 폴더에 만들고 `Blog Post` 템플릿을 넣습니다.
- `draft: true`인 글은 올라가지 않습니다. 공개할 때 `false`로 바꾸거나 줄을 지웁니다.
- `date`가 있어야 홈 화면 목록에 나옵니다.
- 수식은 `$x^2$`(문장 안)나 `$$ ... $$`(따로 한 줄)로 씁니다.
- 다 쓰면 터미널에서 `sh ~/Desktop/개인/프로젝트/choimino-blog/scripts/publish.sh "새 글: 제목"`을 실행합니다.
